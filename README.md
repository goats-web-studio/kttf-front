# kttf-front

React PWA. Отдельное приложение, собирается Vite в статику.

**Пока пусто.** Разворачивается после `kttf-shared/brackets` — см. `docs/05-state.md`.

## Одно приложение, не два

Публичная часть, кабинеты и консоль судьи живут здесь вместе: одна точка входа, одна установка PWA, одна сессия. Отдельного приложения под консоль нет и не будет — ADR-004.

## Что из этого следует для консоли

`src/features/console/` — модуль проведения турнира в зале. Три требования, которые нельзя нарушить:

1. **Ввод счёта никогда не ждёт сеть.** Оптимистичное обновление обязательно, отклик < 50 мс. Бриф, запрет №1
2. **Чанки консоли обязаны быть в Workbox precache.** Ленивый чанк без предзагрузки в офлайне недоступен: судья откроет консоль в зале без сети и получит пустой экран. Самый вероятный способ сломать офлайн-режим в единой сборке
3. **Бюджет < 400 КБ gzip на набор чанков консоли.** Тяжёлое из публичной части (графики, карты) сюда попадать не должно

Требования к консоли целиком — `docs/02-requirements.md`, раздел 6.
